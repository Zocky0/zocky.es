What Data We Collect

ZockyNet collects only the minimum data necessary to operate the bot and provide its features. Specifically:

  • Discord User ID — A unique numeric identifier provided by Discord. This allows the bot to identify who is using each command and manage permissions correctly.
  • Discord Server (Guild) ID — To know which server the bot is operating in and apply server-specific configurations.
  • Commands used — We log which commands are executed (e.g. /launch, /games) to monitor bot performance and detect errors. We do not store message content.

We do not collect usernames, email addresses, passwords, payment information, or any personal information beyond what is listed above.

How We Use Your Data

The data collected is used exclusively for the following purposes:

  • Providing and maintaining the bot's core functionality (game launcher control via Discord commands)
  • Identifying users to apply correct permissions and personalized settings
  • Diagnosing technical errors and improving bot performance
  • Preventing abuse and ensuring compliance with our Terms of Service

We will never sell, rent, or trade your data to third parties.
